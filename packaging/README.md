# Packaging

This folder builds the Windows installer for Alidade with Inno Setup 6.

## Build locally

Requirements: Rust toolchain, Inno Setup 6 (`winget install JRSoftware.InnoSetup`).

```powershell
.\packaging\build-installer.ps1
```

This reads the version from `Cargo.toml` (`[workspace.package] version`),
runs `cargo build --workspace --release`, then compiles
`packaging\alidade.iss` with ISCC.

Add `-SkipBuild` to reuse existing release binaries and only run ISCC:

```powershell
.\packaging\build-installer.ps1 -SkipBuild
```

The script looks for `ISCC.exe` in this order: on `PATH`, at
`%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe` (a per-user winget install),
then at `C:\Program Files (x86)\Inno Setup 6\ISCC.exe` (the path on GitHub's
`windows-latest` runner). It fails with an error if none of these exist.

## Output

The installer lands at `target\installer\alidade-setup-<version>.exe`.

## Test a silent install

```powershell
.\target\installer\alidade-setup-0.1.0.exe /VERYSILENT /SUPPRESSMSGBOXES
```

`/VERYSILENT` skips all wizard pages. `/SUPPRESSMSGBOXES` skips information
boxes. The uninstaller question about deleting data is also skipped in
silent mode: it keeps the data.

## Uninstall registry entry

The installer is per-user, so it writes under `HKCU`, not `HKLM`:

```
HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\{1D8A1348-B80B-4CC7-BEF4-B7DB2E97B70F}_is1
```

This is what Windows reads for the Programs and Features / Installed Apps
list: `DisplayName`, `DisplayVersion`, `Publisher`, `UninstallString`,
`DisplayIcon`.

## Icon

`assets\icon.ico` is generated by `packaging\make-icon.py` from
`assets\icon.svg` and committed to the repository. The build does not need
an SVG rasterizer.
