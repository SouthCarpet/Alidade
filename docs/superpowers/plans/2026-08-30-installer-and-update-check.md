# Alidade: Windows installer, uninstaller, update check (plan 064)

Approved by Michal 2026-08-30 in chat (design questions answered 2026-08-29).

## Goal

Give Alidade a per-user Windows installer that Windows can find and remove
through Programs and Features, and make the existing update check reachable
so the app can say "a newer version exists" without ever installing it.

## Decisions (do not re-open)

- Tool: Inno Setup 6. Per-user (`PrivilegesRequired=lowest`), target
  `{localappdata}\Programs\Alidade`, no UAC.
- Shortcuts: desktop (checkbox, default on) and Start Menu (always).
  No PATH entry, no autostart from the installer.
- Upgrade in place: fixed `AppId`, `CloseApplications=yes`. Data survives.
- Uninstall asks once, before files go: delete measured data (database and
  settings) or keep. Default button = keep. `/SILENT` skips the question and
  keeps. Data means `{localappdata}\Alidade` and `{userappdata}\Alidade`.
- Update check: opt-in `check_updates` in `ui-settings.toml` (default
  false), toggle on the Settings screen. One async check on app boot, no
  timers, no throttling. Result: one line in the app header,
  "Dostupná je verzia vX.Y.Z", click opens the release page in the browser.
  Never downloads. Notes stay on GitHub.
- Icon: `assets/icon.ico` is generated by `packaging/make-icon.py` and
  committed. CI needs no rasterizer.
- Version comes from `Cargo.toml` (`[workspace.package] version`), passed to
  ISCC as `/DAppVersion=`.

## Phases and tasks

### p1-packaging

**T1 (maker, sonnet):** `packaging/alidade.iss`, `packaging/build-installer.ps1`
(reads the version, calls ISCC, prints the output path), `packaging/README.md`,
`INSTALL.md` rewrite (drop "There is no installer"), `release.yml` step that
builds the setup on `windows-latest` (ISCC is preinstalled there) and attaches
`alidade-setup-<version>.exe`, CHANGELOG line under Unreleased.

Files installed: `alidade-app.exe`, `alidade.exe`, `LICENSE-MIT`,
`LICENSE-APACHE`, `NOTICE.md`. Uninstall registry entry gets DisplayIcon,
Publisher `SouthCarpet`, URL of the repo, version.

### p2-update-check

**T2 (maker, sonnet):** wire `app/src/update.rs`. Add `check_updates: bool`
to `UiSettings` (default false, serde default so old files load). Settings
screen checkbox. On boot, if enabled, `Task::perform(update::check(...))` with
a new `Message::UpdateChecked(Option<Release>)`; errors become `None` (quiet).
Header line in `ui.rs` when `App::available_update` is `Some`; press opens
`release.url` through the `open` crate. Remove the KNOWN_ISSUES entry.
Tests: serde default for the new field, boot does not call out when the flag
is off, `is_newer` tests already exist.

### p3-verify

**T3 (verifier, opus):** build the installer locally, install, check the
`HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\Alidade_is1` key,
both shortcuts, app launch (20 s wait), uninstall both ways and inspect what
remains. Run `cargo test --workspace` and clippy. Wizard pages screenshots go
to Gemini (plan 040). Verdict PASS/PARTIAL/FAIL.

## Out of scope

Code signing, MSI, auto-download, autostart, PATH, in-app release notes.
