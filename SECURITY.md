# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through a [private GitHub security advisory](https://github.com/SouthCarpet/Alidade/security/advisories/new) for this repository. Include enough detail to reproduce the issue and, if possible, its impact.

Please do not open a public issue for a vulnerability before it has been reviewed.

## Scope

Security reports are welcome for the Alidade source code, release binaries, build and release workflows, local SQLite data handling, and network behavior initiated by the application.

This is a personal project. There is no service-level agreement and no guaranteed response or remediation time.
